商業寬頻

辦公室、店舖同其他商業地址，揀寬頻時要一齊睇穩定性、上下載需要同支援服務。

  • 01 / 選購重點先核實地址

    商廈、工廈同地舖嘅線路覆蓋可能唔同，先向供應商提供完整地址核實。

  • 02 / 選購重點睇清上下載速度

    如果經常視像開會、上傳檔案或者用雲端系統，記得同時比較上載同下載要求。

  • 03 / 選購重點問清支援條款

    留意安裝時間、維修支援、設備、固定 IP 需要同合約總費用。

HOW TO CHOOSE / 選購重點

家居寬頻，唔好只睇月費。

同一價錢未必適用於每個地址；比較時將網速、合約同安裝條件一齊睇。

01 / 地址

先確認覆蓋

同一屋苑唔同座數或單位，安裝情況都可能有分別。搵到計劃後，用完整地址向供應商確認。

02 / 費用

計埋整段合約

除咗每月月費，仲要睇安裝費、設備費、免費月份同合約期，先知實際支出。

COMMON QUESTIONS / 常見問題

揀計劃前，
你可能想知。

搜尋到屋苑，就代表一定裝到？

唔一定。屋苑資料只幫你縮窄選擇；供應商仍須按座數、樓層、單位同走線情況確認覆蓋。

點樣比較兩個寬頻計劃？

先比較適用地址、網速、每月月費同合約期，再核對安裝費、設備、免費月份及合約完結後收費。

村屋可以直接揀光纖計劃？

村屋嘅可裝速度同走線安排因地址而異。先查看村屋類型計劃，再向供應商提供完整地址核實。
